🚗 WPF Helix3D – OBJ Model Decomposition & Reconstruction

A WPF application using HelixToolkit (Helix3D) that demonstrates how to load, split, manipulate, and reconstruct 3D OBJ models dynamically, along with applying targeted animations using a behavior-based approach.

📌 Overview

This project showcases a practical workflow for handling complex 3D models in WPF:

Load a full OBJ model (car)

Break it into smaller parts using GeometryModel

Interactively filter components

Rebuild a new model from selected parts

Apply animations to specific sub-parts (e.g., wheels)

This is especially useful for developers working on:

CAD-like tools

3D visualization apps

Engineering or simulation software

✨ Features

📦 Load and render complex OBJ models

✂️ Split model into individual GeometryModel parts

📋 Display parts in a ListView

🧹 Remove unwanted model components dynamically

🧩 Reconstruct a new OBJ model from selected parts

🎞️ Apply rotation animation to specific components

🧠 Behavior-based animation (MVVM-friendly)
